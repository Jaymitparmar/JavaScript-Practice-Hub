
# JavaScript Iteration Statement Assignment

## 📌 Project Overview

This project contains basic JavaScript programs based on iteration statements and loops. It helps beginners understand `for` loops, `while` loops, nested loops, digit operations, and number series.

## 🛠️ Technologies Used

- HTML5
- JavaScript

## 📚 Topics Covered

### 1. Number Series Using For Loop
- Print a number series using a `for` loop.
- Understand loop conditions and increment operations.

### 2. Disarium Number
- Count the digits of a number.
- Calculate digit powers using nested loops.
- Check whether a number is a Disarium number.

### 3. Sum of Digits Until a Single Digit
- Add the digits of a number repeatedly.
- Use nested `while` loops to get a single-digit result.

### 4. Count Digits
- Count the total number of digits in a number.
- Use a `while` loop and `Math.floor()`.

### 5. Sum of First and Last Digit
- Find the first digit and the last digit of a number.
- Calculate their sum using arithmetic operators and a `while` loop.
